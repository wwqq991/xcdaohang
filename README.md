## 我为什么要搞这个

其实就是当书签在用。收藏夹里的网站越来越多，浏览器书签栏不够塞，正好 MeNav 这个项目能解决这个问题，我就 fork 过来自己维护了。

后来发现，既然维护起来了，不如顺手分享出去——有些网站和工具确实好用，自己找还费劲，放这儿别人也能用。

## 这里都有些啥

站里分两块：**常用** 和 **精选**。

### 常用

日常高频访问的网站，覆盖了大部分人的日常需求。大概分这些类：

- **搜索与问答**：Google、百度、知乎、Stack Overflow……
- **AI 工具**：ChatGPT、Claude、Gemini、Perplexity、DeepSeek 等等——市面上能叫上名的基本都收了
- **视频与内容**：YouTube、B站、少数派、掘金、网易云音乐
- **新闻资讯**：人民网、澎湃、参考消息……
- **社交与社区**：X、Reddit、微博、豆瓣、小红书、Telegram、吾爱破解
- **效率工具**：Notion、飞书、腾讯文档、Trello、Todoist
- **邮箱与云盘**：Gmail、QQ邮箱、Google Drive、百度网盘、阿里云盘，外加几个临时邮箱
- **开发效率**：GitHub、Vercel、Cloudflare、MDN……
- **设计与素材**：Figma、Canva、Unsplash、Iconfont
- **学习与课程**：Coursera、LeetCode、菜鸟教程、中国知网
- **购物**：淘宝、京东、拼多多、闲鱼、1688

没什么特别的技术含量，就是整理得比较全，自己用着方便。

### 精选

这才是这个站有意思的部分——**真实用过才放进来**。

**VPS 和云服务**——我平时喜欢折腾便宜的 VPS，踩过不少坑也捡过不少漏。里面的链接都是真实使用过的（除了 dmit，因为我没抢到）。不好用的我会直接说，比如：

- "便宜机器几乎无售后"
- "性价比高的常年缺货"
- "价格很低，但几乎完全无售后"
- "还好，但长期缺货"

不吹不黑，你从描述就能看出来我是真用过还是随便贴的。

**AI API 中转站**——OpenRouter、SiliconFlow、Right Codes、FreeModel……我试过的 AI 聚合/中转平台都放这儿了。有贵的稳的，有便宜的能用的，有送免费额度的。我自己日常就在这些平台上跑模型，哪个快哪个便宜哪个容易断，心里都有数。（如果愿意用我的邀请链接就更好了）

**自建小服务**——邮箱、音乐、PDF 工具、在线白板、文件快递柜、网盘搜索、DOS 怀旧游戏、在线小说阅读、文言文加密……都是自己搭在廉价 VPS 上的。不过一部分已经关掉了，因为实在是没太大用。

标准是：能用就行，够用就好。不求 fancy，反正自己用着顺手。

**省钱相关**——免费域名、低价 VPS、拼车代充、eSIM 流量卡、虚拟信用卡。白嫖的结果不重要，主要是白嫖的过程有意思。

**关于链接里的 aff**——大部分链接都挂了 aff，但有一点：我不会为了赚 aff 而推垃圾东西。放上来的首先是因为我自己觉得值得用，aff 是顺便。
